El maíz no llega a 3:1 de contraste sobre el fondo cal. Va solo como relleno o como trazo grueso, nunca como texto pequeño.

## Tipografía

- Ancízar Serif Bold para el nombre y los títulos.
- Ancízar Sans para el texto.

Ancízar es la familia institucional de la UNAL, con licencia SIL OFL 1.1 (`tablero/static/OFL-Ancizar.txt`).

## Regla del tramo cerrado

Rojo sobre verde es el par difícil para el daltonismo. Un tramo cerrado nunca se distingue solo por el color: va en tierra roja, punteado y con una equis o una etiqueta.
